Google Ads — sắp có

Google Ads không cho đọc dữ liệu qua phiên đăng nhập như Facebook. Hai hướng làm tiếp:

  1. Google Ads API (chuẩn, ổn định): cần developer token + OAuth của tài khoản MCC. Có token là nối được ngay vào bảng này.
  2. Đọc trực tiếp trang ads.google.com đang mở (content script): không cần token nhưng dễ vỡ khi Google đổi giao diện.

Bạn chọn hướng nào thì extension sẽ được nối thêm ở tab này.
